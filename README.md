# Cristina Ulucanlı Beauty — interactive proposal

Turkish presentation website. Static HTML, CSS and JavaScript, suitable for GitHub Pages. The proposal is viewed directly in a browser, with no download buttons and no backend.

## Features

- Instagram before/after slider using supplied screenshots and a proposed HTML layout.
- Monthly content mix, local Google Maps journey and image previews.
- Package selection, a message/appointment option for package 3 and comparison dialog.
- Weekly management fees, monthly deliverables and independent services.
- Responsive layouts, accessible tabs/dialogs, keyboard controls and reduced-motion support.

The online booking/admin panel is a separately offered salon service, illustrated in the proposal. This website does not collect or book appointments.

## Sources and image disclosure

Current Instagram/Google screenshots were supplied by the user. Proposed layouts and example Maps/review/email/booking/print illustrations are identified as illustrative on the page. UI mockups do not represent real ratings, reviews, booking systems or achieved search rankings.
